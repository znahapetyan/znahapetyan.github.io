Work

From my current role at Version Story, a document comparison tool for law firms. Screenshots use demo documents.

Quick Compare

Compare contract drafts from the first screen

New users had to create a project before they could compare anything, but many just wanted to see what changed between two drafts. I pitched putting comparison on the first page, prototyped it, and shipped it: originals on one side, modified versions on the other, and each pair gets a redline to open or download.

  • New users' time to their first comparison went from about 10 minutes to about 4.
  • Usage grew about 5x and brought in many new customers.

Built with React, TypeScript

Side projects

Tools I built for my own workflow.

Claude Canvas

All your Claude Code conversations on one canvas

Each Claude Code conversation is a card with its title, latest message, and live status, so I can see at a glance which ones are working, finished, or waiting for me. Conversations started in a terminal appear on their own, and a click jumps back to the right Warp tab. I use it every day, at work and on all my projects.

  • Drag cards into groups, add titles, and leave yourself notes on any card.
  • Pull requests a conversation opened show on its card, with their current state.
  • A small Node server with no dependencies watches Claude Code's session files and pushes changes to the page.

Built with JavaScript, Node.js

Mac Island

A Dynamic Island for the MacBook notch

Turns the notch into a small, useful space: what's playing, a drag-and-drop file shelf, and my own tools one click away.

  • Shows what's playing in any app, from Spotify to YouTube in a browser, with a full player that opens from the notch.
  • A file shelf: drop files in and drag them out later. New screenshots land there on their own.
  • Shows AirPods battery when they connect, and starts Claude Canvas from a Tools tab.

Built with Swift, SwiftUI, AppKit, and Claude Code
